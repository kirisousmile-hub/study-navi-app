# 学習ナビアプリ（Study Navi）

生成AIエンジニアコースの教材復習を支援する、  
**壁打ち型 RAG 学習アプリ**です。

教材PDFやメモを取り込み、根拠つきで質問回答・壁打ち・復習を行うことを目的としています。  
単に教材を検索して答えを返すだけでなく、**教材理解 → 対話による整理 → 復習による定着** までを一連の流れとして支援することを目指しています。

---

## 主な機能

- PDF / TXT / DOCX / CSV の取り込み
- ベクターストア検索（RAG）
- 教材を根拠にした質問回答
- 壁打ちチャット機能
- 壁打ち履歴の要約
- 回答内容の復習カード化
- 復習タブでの確認・採点・更新
- 学習状況の簡易分析

---

## 画面構成

- **学習**
  - 教材をもとに質問し、根拠つきで回答を得る
- **壁打ち**
  - 対話形式で理解を深める
- **復習**
  - 保存したカードを見返し、復習状況を更新する
- **分析**
  - 学習状況や弱点を確認する
- **教材管理**
  - 教材追加とインデックス作成を行う

---

## ユーザーフロー

Study Navi は、単に教材を検索するだけのアプリではなく、  
**教材理解 → 対話による整理 → 復習による定着** までを一連の流れで支援する学習アプリです。

現在の画面構成に沿ったユーザーフローは、次のようになっています。

### 1. 教材管理
最初に、ユーザーは教材PDFやメモを取り込みます。  
教材管理タブでインデックスを作成することで、アプリが教材内容を検索できる状態になります。

この段階の目的は、後の質問回答や壁打ちで参照するための**学習の土台を作ること**です。

ユーザーが行うこと:
- PDF / TXT / DOCX / CSV をアップロードする
- ローカル教材を読み込む
- インデックス作成を実行する

---

### 2. 学習タブで質問する
教材を取り込んだ後、学習タブで分からないことを質問します。  
アプリは教材を検索し、その内容を根拠として回答します。

この段階では、単にLLMが一般論で答えるのではなく、  
**教材に基づいた回答と参照ソースを確認できる**ことを重視しています。

ユーザーが行うこと:
- 教材について質問する
- 回答を確認する
- 参照ソースを確認する
- 必要に応じて自己テストを作る
- 必要に応じて回答を復習カード化する

---

### 3. 壁打ちタブで理解を深める
質問で答えを得るだけではなく、壁打ちタブで対話しながら理解を整理します。  
ここでは、用語理解・設計理解・コード理解などの観点から、学習内容を深掘りできます。

この段階の目的は、  
**「分かったつもり」を減らし、自分の言葉で説明できる理解に近づけること**です。

ユーザーが行うこと:
- 曖昧な点を会話形式で入力する
- AIの問い返しや補足説明を受ける
- 必要に応じて壁打ち内容を要約する
- 必要に応じて要約を復習カード化する

---

### 4. 復習タブで定着させる
学習タブや壁打ちタブで得た内容は、復習カードとして保存できます。  
復習タブでは、それらのカードを見返し、理解度に応じて採点し、次回復習日を更新します。

この段階の目的は、  
**その場の理解で終わらせず、後から見返せる形にして定着につなげること**です。

ユーザーが行うこと:
- 保存したカードを選ぶ
- 問題や答えを確認する
- 理解度を採点する
- 次回復習日を更新する
- 不要なカードを削除する

---

### 5. 分析タブで弱点を確認する
分析タブでは、学習履歴をもとに理解度や弱点を確認できます。  
学習ダッシュボード、弱点ヒートマップ、Knowledge Map などを通して、次にどこを学ぶべきか判断しやすくします。

この段階の目的は、  
**学習を感覚ではなく記録ベースで振り返ること**です。

ユーザーが行うこと:
- 学習ダッシュボードを見る
- 弱点ヒートマップを見る
- Knowledge Map を確認する
- 弱点分析を実行する
