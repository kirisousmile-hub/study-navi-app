# 学習ナビアプリ（Study Navi）

生成AIエンジニアコースの教材復習を支援する、  
**壁打ち型 RAG 学習アプリ**です。

教材PDFやメモを取り込み、根拠つきで質問回答・壁打ち・復習を行うことを目的としています。

---

## 主な機能

- PDF / TXT / DOCX / CSV の取り込み
- ベクターストア検索（RAG）
- 教材を根拠にした質問回答
- 壁打ちチャット機能
- 壁打ち履歴の要約
- 回答内容の復習カード化
- 復習タブでの確認・採点・更新
- 学習状況の簡易分析

---

## 画面構成

- **学習**
  - 教材をもとに質問し、根拠つきで回答を得る
- **壁打ち**
  - 対話形式で理解を深める
- **復習**
  - 保存したカードを見返し、復習状況を更新する
- **分析**
  - 学習状況や弱点を確認する
- **教材管理**
  - 教材追加とインデックス作成を行う

---

## 現在の構成

- `app.py`

- `core/rag.py`
  - 検索、rerank、RAG回答
- `core/coach.py`
  - 壁打ち、要約、長期記憶
- `core/review.py`
  - 復習カード管理
- `core/materials.py`
  - 教材読み込み、分割
- `core/vector_db.py`
  - ベクトルDB管理
- `core/learning.py`
  - 学習プロフィール、弱点管理
- `core/knowledge_map.py`
  - Knowledge Map 表示
